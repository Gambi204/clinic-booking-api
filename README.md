# Clinic Booking API

A production-minded REST API for managing doctor availability and patient appointments in a small clinic.

This project is being developed as part of the Savannah Informatics Backend Developer Take-Home Assessment.

## Current Status

Project foundation created.

## Planned Technology Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- pytest
- GitHub Actions
- Render

## Documentation

Interactive API documentation will be available at `/docs`.

A secondary ReDoc interface will be available at `/redoc`.

- `GET /`
- `GET /health`
